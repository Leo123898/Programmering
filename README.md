# Programering

Detta är ett enkelt webbprojekt för HTML, CSS och JavaScript.

## Öppna projektet

Öppna filen `index.html` i en webbläsare för att se startsidan.

## Exempel

- `fredag 34.html` innehåller ett exempel med regnbågsformade ringar.
- `Programering.html` innehåller ett exempel med en enkel figur.

## Tips

- Ändra text och layout i `index.html` och `styles.css`.
- Lägg till fler sidor och interaktioner i `script.js`.
